# 05 — Stratejik Odak Memoları

İyiBiri'nin sırada ne yapacağı, neyi öldüreceği, hangi segmentten başlayacağı gibi kararlar için memolar. Bu klasör projenin **"pusulası"**.

Dosya formatı: `YYYY-MM-DD-konu-slug.md`.

Beklenen başlıklar:
- `YYYY-MM-DD-ilk-yil-north-star-metrik.md` — NSM seçimi + kalibre
- `YYYY-MM-DD-launch-sehri-secim-kriterleri.md` — İstanbul mu, pilot şehir mi?
- `YYYY-MM-DD-kill-keep-listesi.md` — Mock bağış akışı: kes, erteletemiş mi?
- `YYYY-MM-DD-odak-olanlar-olmayanlar.md` — bir paragraflık stratejik pozisyon beyanı

Her memo şu soruları cevaplar:
1. **Şimdi mi?** Pazar hazır mı, biz hazır mıyız?
2. **Biz mi?** Kazanmak için hangi kapasiteye sahibiz, hangisi eksik?
3. **Ne için?** Hangi yeteneği building mod'da geliştirmek, neyi satın almak/ortaklaşmak?
4. **Ne pahasına?** Maliyet, fırsat maliyeti, risk.

Çıktı formatı tek cümlelik **stratejik pozisyon**la biter:
> "[Kimin için] / [hangi acıyı] / [nasıl] / [hangi yolla çözerek] / [hangi avantajı elde edeceği ürünüz]."
