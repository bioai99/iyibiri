# 01 — Pazar Analizi Memoları

Pazar büyüklüğü, segmentasyon, trend ve makro bağlam memoları burada toplanır.

Dosya formatı: `YYYY-MM-DD-konu-slug.md`.

Beklenen ilk memolar:
- `YYYY-MM-DD-turkiye-stk-bagis-pazari-buyuklugu.md` — TAM/SAM/SOM
- `YYYY-MM-DD-hedef-kitle-segmentasyonu.md` — 18-34 şehirli + sub-segmentler
- `YYYY-MM-DD-gamified-giving-trend-analizi.md` — global + TR trendleri
- `YYYY-MM-DD-makro-ortam-pestel.md` — politik/ekonomik/teknolojik çerçeve
