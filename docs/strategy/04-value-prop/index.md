# 04 — Value Proposition Memoları

İyiBiri üç taraflı bir pazar yeri (marketplace): **kullanıcı** ↔ **STK** ↔ **Sponsor Marka**. Her taraf için ayrı value proposition canvas + cross-side network effect analizi.

Dosya formatı: `YYYY-MM-DD-konu-slug.md`.

Beklenen memolar:
- `YYYY-MM-DD-value-prop-kullanici.md` — Jobs-to-be-done, acılar, kazanımlar, farklılaştırıcı.
- `YYYY-MM-DD-value-prop-stk.md` — STK'ya neden ortak olmalı; gönüllü erişimi, membership yönetimi, veri.
- `YYYY-MM-DD-value-prop-sponsor-marka.md` — Marka için CSR raporlanabilirliği, Gen Z erişimi, brand affinity.
- `YYYY-MM-DD-network-effect-haritasi.md` — Tarafların birbirini nasıl güçlendirdiği; chicken-and-egg çözüm sırası.

Her memo şu framework'leri kullanır (skill referansı):
- Value Proposition Canvas (Strategyzer)
- Jobs-to-be-Done (Christensen)
- Kano Model (must-have / performance / delighter)
