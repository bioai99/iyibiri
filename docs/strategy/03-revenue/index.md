# 03 — Gelir Modeli Memoları

İyiBiri'nin gelir kolları, birim ekonomi (unit economics), fiyatlandırma senaryoları ve duyarlılık (sensitivity) analizleri.

Dosya formatı: `YYYY-MM-DD-konu-slug.md`.

Test edilecek gelir kolları hipotezi:
1. **NGO üyelik komisyonu** — aylık plan başına %X.
2. **Sponsor marka aracılık** — Karma → ödül dönüşümünde marka ödeme (CPM/CPA benzeri).
3. **Premium kullanıcı katmanı** — rozet, seri koruma, özel görev, ad-free.
4. **Bağış fee** — kullanıcı opsiyonel + hizmet bedeli (%0-5).
5. **Kurumsal CSR B2B** — şirketlerin çalışanlarına İyiBiri içinden gönüllülük paketi; SaaS fiyatı + success fee.

Her gelir kolu için beklenen memo iskeleti:
- Mekanizma, taraflar arası değer akışı
- Fiyat aralığı senaryoları (konservatif / orta / agresif)
- Unit economics: CAC, LTV, gross margin
- Karşılaştırmalı benchmark
- Risk haritası
- Öneri: bu kol primary, secondary, yoksa kill?
