# 06 — Cross-Cutting Memolar

Tek klasöre sığmayan, birden çok başlığı kesen stratejik memolar. Örn. yönetim kurulu sunumu özetleri, yıllık strateji güncellemeleri, pivot kararları, "ne değişti" özetleri.

Dosya formatı: `YYYY-MM-DD-konu-slug.md`.

Örnekler:
- Yıllık strateji raporu
- Çeyreklik pivot notu
- Pazar + rekabet + finans kesişen "state of İyiBiri" memo'su
- Board-ready 1-pager özeti
