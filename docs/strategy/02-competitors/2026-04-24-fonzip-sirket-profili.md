## Güçlü Yanlar

1. **10 yıllık marka ve müşteri güveni.** TEMA, AKUT, Kızılay gibi devlerin uzun-dönem müşterisi.
2. **STK uzmanlığı** ekipte (Greenpeace, WWF, UN WFP mezunları) — domain knowledge çok yüksek.
3. **Dernekler/Federasyon düzeyinde ağ** — tek-tek satış değil, sektör genelinde yayılma.
4. **Oturmuş makbuz + muhasebe + KVKK süreçleri** — hukuki karmaşıklık zaten çözülmüş.
5. **Integrations** (Mailchimp, Stripe, vb.) — ekosistem içinde.

## Zayıf Yanlar

1. **Küçük ekip (2-10)** — yeni özellik geliştirme hızı sınırlı, büyük roadmap support zayıf.
2. **Kullanıcı-yüzüne zayıf** — tamamen B2B SaaS. Kullanıcı (bağışçı, gönüllü) fonzip'i hiç görmüyor.
3. **Gamification yok** — İyiBiri'nin Karma + seri + leaderboard'u fonzip'te yok.
4. **Mobile-öncelikli değil** — web SaaS ağırlıklı.
5. **Cross-STK keşif yok** — kullanıcı gözünden tek-STK deneyimi.
6. **Modern ürün bakış açısı sınırlı** — eşik: orta-yaş STK personelinin tanıdığı arayüz.
7. **Fiyat küçük STK için yüksek** — ₺499/ay yıllık ₺6k + %1.5 bağışın + 0.05₺ email küçük STK'ya (örn. 50 üye) ağır.

## Partnership Olasılığı (Yol D için fizibilite)

**Fonzip ile ortaklık senaryoları:**

### Senaryo 1: Affiliate / Referral (İyiBiri → fonzip'e kullanıcı yollar)
- İyiBiri STK'ya "fonzip kullan" önerir.
- STK zaten fonzip müşterisiyse İyiBiri'den gelen bağışlar fonzip üzerinden akar.
- Fonzip İyiBiri'ye referral commission (%0.5-1 bağışın üzerinden veya flat/ay per-NGO).

**Fizibilite:**
- Fonzip public affiliate programı **yok** — hand-sold görüşme gerekir.
- CEO Emre Danacı ile direkt konuşma gerekir.
- Fonzip %1.5 platform fee kazanıyor — %0.5 vermesi margin'in 1/3'ü, genelde kabul etmezler.
- Volume argümanı: "İyiBiri size aylık X bağış volume getirecek — size kazandıracak" pitch'i gerek.
- Fonzip İyiBiri'yi tehdit görürse (user acquisition channel'a çevirip gelecekte baypas etme riski) kabul etmez.

### Senaryo 2: Teknik Entegrasyon (embedded widget)
- Fonzip'in embed özelliği (fonzip widget İyiBiri iframe'e) kullanılır.
- Finansal anlaşma yok — sadece teknik uyumluluk.
- İyiBiri gelirini doğrudan STK'dan alır (SaaS fee + referral fee — ADR-008 v2 modeli).
- Fonzip müşteri STK'ları için backend zaten fonzip, İyiBiri sadece yüz.

**Bu zaten ADR-008 v2'de embedded mod.** "Fonzip ile özel anlaşma" değil — teknik entegrasyon standart.

### Senaryo 3: Satın Alma / Birleşme (Uzun Vade)
- Yıl 3+'ta İyiBiri + fonzip birleşmesi teorik olarak mümkün.
- İyiBiri'nin B2C + Karma tarafı + fonzip'in B2B + müşteri ağı = güçlü combined.
- 2-10 kişilik şirket satın alma makul ölçekte.
- Şu an için erken düşünce.

## Fonzip'e Karşı / Birlikte Konumlanma Seçenekleri

### Karşı oynamak (Yol B — tam fonzip parite)
"Fonzip'ten daha iyi SaaS" pitch. Müşteri çalma. Agresif. 9-12 ay geliştirme + marketing.

### Birlikte oynamak (Yol D — partnership)
"Fonzip'in user acquisition kanalı" pitch. Fonzip margin'inden küçük pay. Hızlı ama bağımlı.

### Yanında oynamak (Yol C — hibrit evrim, önerim)
"Fonzip'i görmezlikten gelmeden, farklı katman olmak" pitch. V1'de embedded uyum, Yıl 2-3'te B2B tarafında agresif — fonzip'in pazarını yavaş yavaş al.

## Önemli Riskler

1. **Fonzip'i rahatsız ederseniz** (agresif pitch, müşteri çalma) — ekosistemde "güvensiz oyuncu" algısı. TR STK sektöründe söylenti hızlı yayılır.
2. **Fonzip partnership umuyorsanız** — Plan B şart. Ret gelirse kayıp olmamalı (Yol C buna hazırlıklı).
3. **Fonzip'in 10 yıllık müşteri güvenini aşmak** — ürün kalitesi + fiyat + hizmet yeterli değil, **güvene erişim yol bulmak** gerek (partnership, referans müşteri, PR).
4. **Fonzip yatırım alır veya satılırsa** — oyuncu değişebilir. (Büyük bir oyuncu satın alırsa — örn. iyzico veya HubSpot Türkiye — rekabet yoğunlaşır.)

---

## Sonuç ve Öneriler

1. **Fonzip TR STK SaaS pazarının kesin lideri.** Onsuz strateji hayalî olur.
2. **Pilot STK'larımızın 2/3'ü fonzip müşterisi** — bunu görmezden gelmek zarar verir.
3. **ADR-008 v2 embedded mod zaten fonzip widget'ını destekliyor** — teknik uyum hazır, anlaşma özel gerekmez.
4. **Yol D (partnership) denenebilir ama Plan B şart** — Yol C hazır-fallback.
5. **Fonzip + İyiBiri uzun vadede tamamlayıcı değil rakip** — İyiBiri büyüdükçe fonzip'in B2B tarafını gelinecek. Bu gerçeği ikinci tarafa erken açıklık.
6. **İlk temas nasıl?** Emre Danacı ile short meeting — "İyiBiri olarak fonzip kullanıcısı STK'lara bağışçı getirmek istiyoruz, teknik uyum + referral commission görüşelim." Samimi, açık, tehdit etmeyen pitch.
