### BUG-001 — P0 — Onboarding flow tamamen atlanıyor

**Severity:** P0 (Blocker)
**Ekran:** /auth/signup → /dashboard (beklenen: /onboarding/welcome)
**Flow:** Faz 1 → A2 + O1-O4
**Cihaz/Viewport:** macOS Chrome 147, ~1200×739 desktop
**Tema:** N/A (state issue)

**Beklenen davranış:**
Signup başarısı → /auth/verify (OTP) → /onboarding/welcome → causes → city → age → /dashboard
`profile.onboarding_completed = true` ve `interests`, `city`, `birth_year` doldu.

**Gerçekleşen davranış:**
Signup'tan **doğrudan /dashboard**'a redirect. Onboarding hiç açılmadı, OTP de yok.

**Repro adımları:**
1. /auth/signup → ad/email/şifre + KVKK → "Hesabımı oluştur" tap

**Supabase state:** Doğrulanmadı (test instance yok, prod read-only). Tahmin: `profile.interests=[], city=null, birth_year=null, onboarding_completed=false` ama route guard yok.

**Kök neden hipotezi:**
- Auth callback handler `onboarding_completed=false` kullanıcıyı /onboarding'e redirect etmiyor.
- VEYA middleware'de onboarding gate yok.
- VEYA signup endpoint'i `onboarding_completed=true` default ile yaratıyor (yanlış default).

**Önerilen fix:**
- `middleware.ts`'te `if (profile.onboarding_completed === false) redirect('/onboarding/welcome')` guard.
- Signup endpoint'inde `onboarding_completed=false` insert.
- /onboarding/* route'larına auth-gated entry.

**ADR ihlali:** ADR-001 (onboarding flow expected) — kontrol gerekli.
**Routing:** frontend-engineer + supabase-backend (auth callback + middleware)

### BUG-006 — P1 — KVKK checkbox native input element yok (a11y)

**Severity:** P1 (a11y blocker)
**Ekran:** /auth/signup
**Flow:** A2

**Beklenen davranış:**
KVKK consent için `<input type="checkbox">` veya en az `role="checkbox"` ile `aria-checked` state.

**Gerçekleşen davranış:**
DOM'da `document.querySelectorAll('input[type="checkbox"]').length === 0` — sadece custom div/button ile gösteriliyor.

**Repro adımları:**
1. /auth/signup
2. DevTools console: `document.querySelectorAll('input[type="checkbox"]').length` → `0`

**Etki:**
- Screen reader (VoiceOver, NVDA) checkbox state'i okuyamaz.
- Keyboard nav (Tab + Space) çalışmaz, mouse-only.
- Form auto-submit pattern (Enter on form) state'i tetiklemez.
- KVKK için bu özellikle kritik — accessibility hukuki gereklilik (WCAG AA).

**Önerilen fix:**
Native `<input type="checkbox" id="kvkk" />` + `<label for="kvkk">...</label>`. Görsel custom styling sürdürülebilir (`visually-hidden` + custom div).

**Routing:** frontend-engineer (signup form component)

### Pattern B — Türkçe karakter integrity

BUG-004 (landing TR copy) + BUG-005 (greeting parse "Biri") + potansiyel future bug'lar.

**Kök neden:** Türkçe karakter handling iki yerde fail ediyor:
1. Copy yazımı (raw text Türkçesiz)

**Sistemik fix:**
- Copy review: tüm static text'leri TR karakter pass'inden geçir.
- Util fonksiyon: `formatDisplayName(input: string)` Türkçe-safe parse.
- Locale aware: `String.prototype.toLocaleLowerCase('tr-TR')` kullan.

**Pattern memo:** `docs/test/_patterns/2026-04-26-tr-character-integrity.md`
**Routing:** frontend-engineer (lead) + ux-researcher (copy review)
