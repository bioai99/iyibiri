## Kategorik özet

### `/dashboard` cold load — 4065ms 🚨

**Asıl sebep:** Login user ilk geldiğinde `/auth/signin`'e gitse middleware redirect ediyor `/dashboard`'a → server side full render + 11 paralel query + image-heavy 5 carousel.

Mevcut state'te (sprint kodu deploy edilmedi):
- 11 query Promise.all paralel (audit'e göre `getAllMissions` limitsiz, `getAllActiveNGOs` limit yok — sprint'te düzeltildi ama prod'da yok).
- Mission carousel 5 Unsplash 850ms each.
- Post rail + sponsor rail + NGO rail (4 ek carousel section).

**Sprint deploy sonrası beklenen:** 4065ms → ~1800ms (query limit + dead deps + cache).
**Faz 1 sonrası beklenen:** ~1800ms → ~1100ms (image migration).

### `/dashboard/missions` 3550KB 🚨

**Asıl sebep:** 5 Unsplash görüntü (`?w=1080` default size), NGO logo (`haytap-logo.png` 927ms), mission cover'lar.

**Faz 1 sonrası beklenen:** 3550KB → ~700KB (-%80) (next/image + size param + WebP/AVIF).

### `/dashboard/ngos/tema/membership` 2049ms 🔴

**Asıl sebep:** `membership-flow-client.tsx` 1103 satır + 17 hook (TD-004 client monolith). Hydration süresi uzun.

**Faz 6 sonrası beklenen:** Client refactor → ~1200ms (Haziran sprint).

### `/dashboard/missions` 1616ms (DOM warm) — anomali

DOM warm normalde load'dan küçük olur ama burada **load > DOM** çünkü 5 Unsplash image lazy load değil, paint sonrası gelmeye devam ediyor → load event 2533ms'ye dek uzuyor.

## Pattern detection (cross-page)

### Pattern A — Image optimization eksik (🔴 high impact)

**Etkilenen 7+ sayfa** (decoded büyüklüğü):
- /missions: 3550KB (5 Unsplash 850ms)
- /dashboard: 2467KB (mission carousel)
- /discover: 1842KB (post + sponsor)
- /ngos/tema: 1315KB (cover + logo)
- /donate/tema: 1253KB (kampanya cover)
- /my-missions: 1255KB (mission cover'lar)
- /donate: 1198KB (NGO logo'lar)

**Kök neden:**
- `next/image` kullanılmıyor (raw `<img>`)
- `next.config.mjs` `images.remotePatterns` eksik
- Lazy loading yok
- WebP/AVIF dönüşümü yok
- Unsplash sized URL parameter (`?w=400&fit=crop`) yok

**Sistemik fix (Faz 1):** ~2 saat, beklenen LCP -%50, decoded -%70.

### Pattern B — Auth/onboarding redirect ölçümü kirliyor (🟢 informational)

`/auth/signin?b=1`, `/auth/signup?b=1` login user için → middleware `/dashboard`'a redirect → ölçüm dashboard sonuçlarını veriyor. Ölçüm metodolojisinde kabul edilebilir; gerçek anonim user için ayrı incognito ölçüm gerek (sonraki tur).

### Pattern C — Legal sayfa son hızı ✅ (örnek)

`/legal/{kvkk,terms,privacy}` 484-626ms DOM Interactive — server-side static markdown render; image yok; minimum bundle. **Bu hedef.**
