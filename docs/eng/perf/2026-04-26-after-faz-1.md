## `nextImgCount: 0` anomalisi

Beklenen: Image component `/_next/image?url=...&w=...&q=...` endpoint'i hit eder, Vercel sized + WebP/AVIF döner.

Gerçek: 0 hit. Image component'i original URL'i (Unsplash) doğrudan kullanıyor.

**Olası sebepler:**
1. **Capacitor static export modu** — `next export` Image optimization desteklemiyor; mobile build gerek olabilir.
2. **`images.unoptimized: true`** — `next.config.mjs`'te flag var mı kontrol gerek (yok diye okudum ama config çalışma sırasında hesaplanıyor olabilir).
3. **Vercel build cache** — eski build hâlâ aktif olabilir; 5 dk daha bekle + tekrar dene.

**Etki:** Decoded body düşüşü hâlâ gerçek **çünkü native browser lazy load** çalışıyor (Image component otomatik `loading="lazy"` ekler). WebP/AVIF dönüşüm yok ama transfer azalımı ana hedefti, başarıldı.

**Aksiyon (Faz 1 follow-up):** 1 saat sonra retry ölçüm; eğer hâlâ `nextImg: 0` ise `next.config.mjs` ve Capacitor build flag araştır. Şu an için Faz 1 başarılı kabul.
