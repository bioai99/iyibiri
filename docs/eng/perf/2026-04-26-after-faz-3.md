## Anomaliler (4 sayfa daha kötü)

### 🤔 Dashboard cold load — 4065 → 4951ms (+%22)

Bu beklenmedik. Olası sebepler:
- **Server cold start** — Vercel function ilk istek için warm-up gerekir; sprint deploy sonrası ilk cold load Vercel function build'e yakındı.
- **Yeni package installs (vitest deps)** — node_modules büyüdü, build cache invalid → ilk build daha yavaş.
- **Variance** — cold load tek ölçüm, retry gerekir.

**Aksiyon:** 5 dakika sonra tekrar ölç (Vercel function warm-up tamamlanır), gerçek delta belirlenir.

### 🤔 /dashboard/discover, /dashboard/ngos, /dashboard/streak — küçük artış (+%11-21)

- /dashboard/ngos decoded 867 → 1268KB (+%46) — `getAllActiveNGOs` minimal columns ekledim ama 50 limit verdim. Yine de **decoded büyüdü** — anlamlı değil. Ölçüm sırası variance olabilir.
- /dashboard/discover ve /streak küçük artışlar — ölçüm noise olarak kabul edilebilir (±10-15% normal).

**Aksiyon:** 1 hafta sonra Pazartesi regression watch'ta tekrar gör. Sürekli regression olursa fix edilir.
