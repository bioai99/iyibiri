## Önemli: ISR davranışı

Önemli bir nokta: legal sayfalarda `?run=1` query string ile yapılan ilk ölçüm **1843ms** çıktı; query string olmadan tekrar **605ms**. Demek ki Next.js ISR query parameter'ları cache key'ine dahil ediyor — `?fresh=` ile cache busting yapan ölçümler ISR'ı bypass eder. Scheduled task'ta `?fresh=` kullanıyoruz; legal sayfalarda **cache hit ölçemiyoruz** bu nedenle. İleride scheduled task script'inde bu sayfalar için `?fresh=` opt-out eklenebilir.
