# 02 — Mühendislik Brief'leri (Lean PRD)

Kodlama tarafına (frontend-engineer / supabase-backend / auth-capacitor) devredilmek için hazırlanmış brief'ler. Lean PRD formatı — one-pager küçük feature için, 2–10 sayfa karmaşık için.

**Dosya:** `YYYY-MM-DD-feature-slug.md`

**Şablon:** `.claude/skills/writing-plans/SKILL.md` içindeki "Lean PRD" bölümü.

**Kural:** Problem → Solution (outcome) → Scope (must/should/won't) → Metric → Dependencies → Open questions. UI karar dikte etme — outcome'u tanımla, "nasıl" tasarım tarafında açılır.
