# UX Brief — Profile (Profil)

**Tarih:** 2026-04-24
**Sahip (brief):** product-analyst
**Sonraki sahip:** ux-researcher → ui-designer → frontend-engineer
**Priority:** P1 · **Effort:** M (1-2 hafta)
**Bağlı ADR:** ADR-001 (NSM = MAKE), ADR-004 (dark-only V1), ADR-009 (KVKK veri indirme)

## 1. Özet (1 paragraf)

Profile (`/dashboard/profile`) kullanıcının **kimlik merkezi**: karma history, tier badge, üyelikler (STK), rozet (achievement), ve veri yönetimi (KVKK indirme). NSM MAKE üzerinde **retention + autonomy** kaldıracı — kullanıcı "ilerleme" görüp güvenle, veri kontrol ve STK bağını hissetmeli. Inline edit (ad/şehir), karma progress bar, mission history timeline, ve data export GDPR uyumlu şekilde sunulmalı.

## 5. Cognitive load

**Azalan:**
- Cover + avatar overlap → visual anchor, kişiselleştirme (identity oluştur).
- Tier badge clarity → "hangi sevideyim" 1 saniyede.
- Progress bar visual → "ne kadar close" immediate understanding.

**Yeni eklenen:**
- Achievement detail modal (future) → "rozet nedir, unlock condition?" tıkla.
- Data export flow → KVKK modal (explanation + download CTA).

## 6. Başarı kriterleri

- **Primary (MAKE KPI):** Profile açan kullanıcının %35+, leaderboard / missions page'e geri navigasyon (retention proxy).
- **Secondary:** Profil edit (inline) tıklama %20+ (autonomy signal).
- **Nitel:** 5-second test → "Kim bu, kaç Karma var, ne seviye?" sorusuna %85+ doğru cevap.
- **Compliance:** KVKK download flow, ERR<1% (veri integrity).

## 7. Kısıtlar

- **Mobile-first:** max-w-lg mx-auto. Desktop padding 20px side.
- **Dark-only V1** (ADR-004).
- **Design system token'ları** — tier badge color consistency.
- **Motion:** Avatar scale-in (0.95 → 1), stat cards stagger (50ms offset), rozet grid stagger.
- **Safe area:** pt-safe (cover), pb-safe (logout button).
- **Loading state:** skeleton avatar + card rows (WS-04 sistemik).
- **Accessibility:** form inputs (edit mode) WCAG 2.1 AA.
- **KVKK:** Veri indirme GDPR Article 20 (portable format JSON/CSV).

## 8. UI ipuçları (tasarımcıya)

- **Cover gradient:** `linear-gradient(135deg, ${c.ink700}, ${c.ink800})` + bottom overlay fade.

- **Avatar:** 
  - 84×84 circle, gold gradient, 3px ink-900 border.
  - Initial (firstName[0]) — display-serif font, 36px, #241E18.
  - Box-shadow: 0 8px 20px rgba(0,0,0,.3), inset 0 1px 0 rgba(255,255,255,.3).

- **Name + tier:** 
  - Name: display-serif 26px, margin 0.
  - Tier badge: TierBadgeDS component.
  - Location: MapPin icon 11px + text 12px ink-300.

- **Karma card:**
  - Bg: ink-800, border: ink-600, rounded 16px, padding 18px 20px.
  - Display: KarmaDotToken (14px) + number (32px gold bold) + label (12px ink-300).
  - Progress bar: 6px height, rounded 999, width `${pct}%`, gradient gold.

- **Stats grid:** 3 col, gap 8px. Each card: rounded 12px, center aligned, minimal padding.

- **Membership list:**
  - Empty: gold soft bg, "Öncüleri keşfet" CTA.
  - List: horizontal scroll (flex gap 12px), each 80×80 grid. Logo 56×56 white circle + image, name 11px ink-300 centered.

- **Achievements grid:** 3 col, gap 10px. Each: rounded 14px, 48×48 circle (gold gradient or ink-600 locked), icon 20px, locked: opacity 0.5.

- **Activity empty:** centered message, bg ink-800, rounded 14px, link to missions in text.

## 9. Test önerisi (UX researcher için)

- **5-second test** — "Bu kişi, hangi seviye, kaç Karma?"
- **Task-based:** "Rozetler bölümüne git, unlock condition'u 'Elmas' rozeti için bul (varsa)."
- **Edit flow:** "Adını değiştirmek istiyorsun, nereye tıklarsın?" (future V1.1).
- **KVKK:** "Verilerini indirmek istiyorsun, nereyi tıklayıp indirirsin?"

## 10. State coverage (MECE)

- **idle:** Initial profile load, all sections rendered.
- **loading:** Profile data fetching. Skeleton avatar + name + karma card + stat rows.
- **empty:** No membership / no rozet unlocked (rare but possible). Section hidden or empty message.
- **edit_mode** (future): Inline edit active, cancel/save buttons visible.
- **error:** Fetch failed. Retry button.
- **success:** Full profile + badges + membership list.

## 11. Tier-1 Benchmark

- **Duolingo:** "Profile page" — level, streak, XP progress bar, achievements grid.
  - **Insight:** Progress bar (visual + numeric) retention critical; level clarity dopamine.

- **Strava:** "Athlete profile" — stats summary (activities, distance, elevation), badges/segments, social follow.
  - **Insight:** Stat cards grid + badge collection = engagement hook; context-relevant stats.

- **Things 3:** "Project page" — completion %, dates, tags, sharing.
  - **Insight:** Simple, clear ownership; export/share opsiyonu autonomy signal.
