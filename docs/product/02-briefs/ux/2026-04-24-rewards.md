# UX Brief — Rewards (Ödüller / Karma Marketi)

**Tarih:** 2026-04-24
**Sahip (brief):** product-analyst
**Sonraki sahip:** ux-researcher → ui-designer → frontend-engineer
**Priority:** P1 · **Effort:** M (1-2 hafta)
**Bağlı ADR:** ADR-001 (NSM = MAKE), ADR-004 (dark-only V1), ADR-003 (reward redemption flow)

## 1. Özet (1 paragraf)

Rewards (`/dashboard/rewards`) Karma'nın **hedefe ulaşma noktası**: kupon + deneyim + bağış seçenekleri. NSM MAKE üzerinde **closure + incentive structure** kaldıracı — kullanıcı "Karma kazandım, şimdi ne yapabilirim" sorusuna visiyon almalı. Search + category/brand filtreleme, karma range slider (affordable discovery), earning progress bar ("unlock X gün sonra"), expiration countdown, ve featured partnership tiles sunulmalı.

- **H3:** Brand/category dropdown yok — tab'lar kategoriye göre ama brand tarafı 15+ marka carousel'de kaybolabilir.

- **H6:** Earning progress bar yok — "şu ödülü açmak için 500 Karma daha gerek, bu görev yaparsam 200 Karma verir" hedefe ilerliş tracing yok.
- **H7:** Featured tile (partnership) solo — artırılabilir (editorial, "yeni ödüller" rail).

## 5. Cognitive load

**Azalan:**
- Search bar prominence → "ne istiyorum?" cevap hızlı.
- Kategori filter clarity → "tür" seçme explicit.
- Unlock countdown visual → "bekleme durumu" ve "süresi" clear.

**Yeni eklenen:**
- Filter kombinasyon → dropdown + tab state yönetimi (complex ama essential).
- Expiration badge → visual clutter ama urgency critical.

## 6. Başarı kriterleri

- **Primary (MAKE KPI):** Rewards açan kullanıcının %25+, filter/search kullanıp henüz afford edemediği ödüle tıklaması (intent to complete mission).
- **Secondary:** Ortalama session time rewards'da **+30 saniye** (discovery deep-dive).
- **Redemption:** Unlocked & affordable ödüller (>5 per user) %15+ redemption rate (Karma → closure).
- **Search engagement:** Search tıklama %20+ (findability signal).
- **Nitel:** 5-second test → "Ne satın alabilir misin?" sorusuna %80+ "ödüller / kupon" cevabı.

## 7. Kısıtlar

- **Mobile-first:** max-w-lg mx-auto. 2-col grid (160px card).
- **Dark-only V1** (ADR-004).
- **Design system token'ları** — gold highlights consistency, lock icon color (ink-300).
- **Motion:** Card grid stagger (50ms offset), featured tile scale-in (0.98 → 1), unlock timer real-time update animation.
- **Safe area:** pb-safe (bottom nav).
- **Loading state:** skeleton search + featured tile + card grid rows (WS-04 sistemik).
- **Performance:** Infinite scroll / pagination, grid virtualization (mobile 100+ cards).
- **Real-time:** Countdown timer (unlock, expiration) — client-side precision (new Date().toLocaleString()).

## 9. Test önerisi (UX researcher için)

- **5-second test** — "Burada ne satın alabilir misin?"
- **Task-based:** "Starbucks kuponunu ara, bulunca tıkla."
- **Filter flow:** "500 Karma'dan az ödüller görmek istiyorsun, nereye tıklayıp ne yapar?"
- **Unlock discovery:** "Bu ödül ne zaman unlock olacak?" (countdown clarity).
- **Redemption intent:** "Satın almak için tıkla, next step ne?"

## 10. State coverage (MECE)

- **idle:** Initial rewards load, all filters available, featured tile + grid visible.
- **loading:** Rewards data fetching. Skeleton featured + card grid rows (16 min).
- **empty:** No results (search "xyz" no match, or filter combo empty). Message: "Bu filtrede ödül yok." + reset link.
- **filter_changing:** Search/dropdown input (debounced fetch).
- **unlock_countdown:** Real-time timer update (countdown <1 hour).
- **error:** Fetch failed. Retry button.
- **success:** Featured + filtered grid, all badges + icons visible.

## 11. Tier-1 Benchmark

- **Starbucks Rewards:** Search rewards, category filter, redeem by points.
  - **Insight:** Search-first UX; quick filter buttons (e.g., "Under 100 points") discovery.

- **Linear Workspace:** Feature picker, search + filter (workspace type, integration type).
  - **Insight:** Multi-axis filter (type + category + status); clear "locked" state; pricing transparency.

- **Airbnb:** Stays search + price range slider + category filter + amenity chips.
  - **Insight:** Slider critical for "affordable discovery"; category chip array (visual), multi-select fluid.

- **Things 3:** Tag filter + due date filter; "upcoming" section with countdown.
  - **Insight:** Time-based sorting + countdown visual (deadline urgency); filter persistence.

## 12. Open decisions (product-analyst karar kuyruğu)

- **Q-1:** Search-first (prominent search bar) vs category-first (tabs) UX? (A/B test candidate).
- **Q-2:** Unlock countdown V1.0 countdown timer (real-time update) mi static "2 gün" label mi? (Real-time complexity vs UX signal).
- **Q-3:** Expiration countdown badge (visual prominence) ne kadar aggressive? (Scarcity + urgency tradeoff).
- **Q-4:** Filter state persistence — user toggle kategoriye, search sonra kadi mi filter persist mi? (Session UX).
- **Q-5:** Infinite scroll vs pagination (mobile UX tradeoff)?
