# 02 — UX Brief'leri

Tasarım tarafına (design-system-keeper agent / insan designer) devredilmek için hazırlanmış brief'ler. Lean — 1 sayfa hedef, taşmaması tercih edilir.

**Dosya:** `YYYY-MM-DD-feature-slug.md`

**Şablon:** `.claude/skills/writing-plans/SKILL.md` içindeki "UX Design Brief" bölümü.

**Kural:** Her brief hangi workstream'e ait, strateji referansı hangi, başarı kriteri ne, açıkça belirtir. İmplementation detayına girmez — outcome'u tarif eder.
