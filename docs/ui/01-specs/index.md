# 01 — Görsel Spec'ler (UI spec)

UX brief → UI spec. Ekran kompozisyonu, token kullanımı, variant, state, motion. Markdown wireframe + Tailwind class referansları. Kod değil.

**Dosya:** `YYYY-MM-DD-feature-slug.md`

**Şablon:** `.claude/skills/visual-spec-writing/SKILL.md`

**Rapor iskeleti:**
```markdown
# [Feature] — UI Spec

**Tarih / Sahip / İlgili UX brief / Durum**

## 1. Layout (ASCII wireframe)
## 2. Hiyerarşi
## 3. Token kullanımı (renk, typo, radius, shadow)
## 4. Variant × state tablosu
## 5. Motion spec
## 6. Responsive notu
## 7. A11y kontrol listesi
## 8. Handoff (frontend-engineer / design-system-keeper)
```
